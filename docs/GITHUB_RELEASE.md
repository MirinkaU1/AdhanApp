# 🌟 AdhanApp v0.1.0 - Première version beta

Première version beta d'**AdhanApp**, l'application de prières islamiques avec gamification.

## 🎯 Fonctionnalités principales

### 🕌 Prières
- Calcul automatique des 5 horaires (GPS + Adhan.js)
- Notifications configurables par prière
- Historique et calendrier de suivi
- Date Hijri avec ajustement

### 🎮 Gamification
- Système d'XP et de niveaux (1-100)
- Quêtes journalières variées
- Badges et récompenses
- Streaks de régularité

### 📖 Coran
- Texte arabe complet + traductions
- Récitations audio multiples
- Marque-pages et lecture continue

### 🧭 Autres
- Boussole Qibla 3D interactive
- Compteur de dhikrs avec haptic feedback
- Mode sombre/clair
- Support multilingue (FR/EN)
- Synchronisation cloud (Supabase)
- Mode offline-first

## 📱 Disponible sur

- ✅ iOS 13.4+
- ✅ Android 6.0+ (API 23)

## 🛠 Stack technique

React Native • Expo • TypeScript • Zustand • Supabase • RevenueCat
